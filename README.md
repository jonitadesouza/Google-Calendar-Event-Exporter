## 📅 Google Calendar Event Exporter

A Google Apps Script that exports all your calendar events along with guest email addresses to a Google Sheet.

### Features
- Fetches all past and future events
- Includes title, timings, description, location, and guests
- Easy to integrate with Google Sheets

### How to Use
1. Open a Google Sheet
2. Go to Extensions > Apps Script
3. Paste the script from `code.gs`
4. Run the function `exportAllCalendarEventsWithParticipants`
5. Authorize if prompted

✅ Done! All events are exported to your sheet.
